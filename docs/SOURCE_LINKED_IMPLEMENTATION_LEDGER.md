## Mission length and consumables — 2026-10-30
- **Official mission:** Revised City of the Ancients Adventure Book p.12, Basic Mission 1, *For a Few Dark Stone More*: Small 2 clues/25 XP/D3 Dark Stone; Medium 3 clues/50 XP/D3+1; Large 4 clues/75 XP/D3+2. https://www.flyingfrog.net/shadowsofbrimstone/pdf/REV__SBCA_AdvBook_WEB.pdf. Implemented as selectable mission length in setup, persisted goal, final clue suppression of normal token effects, and exact completion reward via rules/mission.js; tested in tests/mission.test.cjs. **Limitation:** current prototype still uses a preselected boss rather than the official Epic Threat/Growing Dread stack resolution; mission cannot be marked complete fidelity.
- **Side Bag healing:** Revised City Rulebook Side Bag section: Bandages heal D6 Wounds, Whiskey heals D6 Sanity. Removed erroneous D6+1 and block supply mutation on failed save; tests/mission.test.cjs. **Limitation:** prototype resource counters still diverge from the persistent five-slot inventory and do not implement all token effects.

## Inventory integration — 2026-10-30
- Five-token Side Bag state is now shared by Hero starting supplies, Bandage/Whiskey/Dynamite consumption, scavenging/loot Bandages, cargo discoveries and town consumable purchases. The bag rejects overflow before spending town money and displays occupied slots. Existing save profiles without inventory are displayed without crashing, but full migration/reconciliation of old expedition saves is **not verified**.
- **Source:** Revised City of the Ancients Rulebook p.7 Side Bag and Creating a Hero, https://www.flyingfrog.net/shadowsofbrimstone/pdf/REV__SBCA_Rulebook_WEB.pdf. **Caveat:** The extra prototype starting supplies (two Bandages, one Whiskey and one Dynamite) are NOT verified as official Hero equipment; official Hero sheets and equipment decks remain unavailable. The bag capacity and token accounting are source-grounded; the contents remain provisional. No complete official Hero class setup, personal item, town event chart or enemy record sheet has been implemented in this change.

## Revised campaign Travel rolls — 2026-10-31
- Source: Revised City of the Ancients Adventure Book p.28, https://www.connexxion24.com/downloads/anleitungen/shadows-of-brimstone-city-of-the-ancients-revised-core-set-abenteuerbuch-auf-englisch-2.pdf . Each Hero rolls D6 to prepare to travel; 1–2 adds one Travel Hazard. Each hazard is rolled on the 3D6 chart (p.56). For the current one-Hero game, rules/travel-phase.js rolls once and, if required, exactly 3D6; the result is persisted.
- The Frontier Town UI **does not grant access** until a triggered Hazard has been explicitly resolved using the printed chart. Unknown chart outcomes are never fabricated. The player must acknowledge actual resolution. The chart effects are NOT automated, and the interface must not claim they are.
- Tests: tests/travel-phase.test.cjs. Further required: full p.56 hazard outcomes, special mission modifiers, camp hazards, daily Town Event and Location Event charts, verified store inventories and prices.

## Enemy tactical movement, footprint-aware spawning, and item upgrade controls — 2026-10-31
- **Publisher source:** Revised City Rulebook, Enemy Movement p.28, Large Enemies p.28, Extra Large Enemies p.30, Enemy Ranged Attacks p.30: https://www.flyingfrog.net/shadowsofbrimstone/pdf/REV__SBCA_Rulebook_WEB.pdf . rules/enemy-tactics.js provides bounded path search to adjacent attack spaces, blocks Hero/other model overlap, checks 2x2 Extra Large footprints, permits Large enemy displacement of smaller enemies, and prevents passage through other Large enemies. Enemy activation uses this path search, and stationary ranged enemies no longer advance when their target is in range and visible. Only enemies whose authenticated record declares size receive non-medium footprints; unverified sizes remain medium.
- **Equipment:** Revised City Rulebook Gear and Artifacts / Item Upgrades, same source. Equipment modal now attaches/removes named upgrades entered from printed cards, validates slot capacity, rejects duplicates, and refuses removal of permanently forged upgrades. All changes persist with the profile; NO upgrade effects are invented. Existing two-hand equipping remains enforced.
- **Tests:** tests/enemy-tactics-equipment.test.cjs (pathing, occupied corridor, Large displacement, 2x2 footprint, upgrade limits and forged removal), tests/tactics-equipment.spec.cjs (browser save/reload and live movement geometry).
- **Not accepted:** exact Large/XL model sheet size metadata, full official 2x2 displacement when multiple smaller models intersect a base, Overflowing the Board, multi-Hero target balancing, movement in every tile shape and OtherWorld, complete enemy sheet data, Epic Threat faces, Sermons, Hero stat sheets, official travel chart effects. This is an incremental implementation, not an official-complete enemy system.
